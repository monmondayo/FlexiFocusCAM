# FlexiFocusCAM

FlexiFocusCAMは、画面上のAF（オートフォーカス）枠を親指で操作できるAndroidカメラアプリです。端末を構えたまま、フォーカス位置・AF枠サイズ・ズーム倍率を画面下部のコントローラーから調整できます。

## 主な機能

- 親指パッドによるAF/AE位置の移動と固定
- AF成功状態を枠の色で表示（黄色／緑色）
- AF枠サイズの調整
- 0.5x・1.0x・2.0xのズーム切り替え
- ズームボタンの長押しによる細かな倍率調整
- JPEG画像を端末の `DCIM/Camera` に保存
- 撮影時の端末回転に合わせた画像方向の設定

## 操作方法

1. 初回起動時にカメラ権限を許可します。
2. 画面下部中央のパッドをドラッグしてAF枠を移動します。
3. パッドを長押しすると、現在位置でAF/AEを再実行します。
4. パッドをダブルタップすると、AF枠が画面中央に戻ります。
5. 縦スライダーでAF枠の大きさを調整します。
6. 左側の倍率ボタンをタップしてズームを切り替えます。長押しすると微調整用スライダーが表示されます。
7. 右下のシャッターボタンをタップして撮影します。

## 動作環境

- Android 8.0（API 26）以上
- 背面カメラ搭載端末
- Android Studio（JDK 17以上）
- Android SDK 36

> [!NOTE]
> 現在の保存処理はScoped Storageを前提としているため、Android 8～9（API 26～28）では写真の保存に失敗する場合があります。Android 10（API 29）以上を推奨します。

## ビルド方法

```bash
git clone https://github.com/monmondayo/FlexiFocusCAM.git
cd FlexiFocusCAM
./gradlew assembleDebug
```

または、Android Studioでプロジェクトを開き、SDK 36をインストールして実機へ実行してください。

## 権限とプライバシー

このアプリが要求する実行時権限はカメラ権限のみです。

- `android.permission.CAMERA`: プレビュー、フォーカス、撮影に使用します。
- インターネット権限は要求しません。
- 撮影画像は端末の `DCIM/Camera` に保存され、アプリから外部サーバーへ送信されません。
- アプリ内データのクラウドバックアップは無効です。

## 既知の制約

- 背面カメラのみ対応しています。
- 動画撮影には対応していません。
- Android 8～9での写真保存は端末によって失敗する場合があります。
- カメラ権限を拒否した場合の案内・再試行UIは未実装です。
- 自動テストはAndroid Studioの初期テンプレート相当で、カメラ操作の実機テストは含まれていません。
